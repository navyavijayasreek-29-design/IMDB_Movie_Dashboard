# 🎬 IMDb Top 250 Movies – Analytics Dashboard

## 📌 Project Overview
This project is an interactive Movie Analytics Dashboard developed using Python, Pandas, and Streamlit.

It analyzes the IMDb Top 250 Movies dataset and provides useful insights through KPI metrics, charts, and interactive filters.

## 🎯 Project Objectives
- Load and explore the IMDb movie dataset.
- Analyze movie ratings and votes.
- Visualize movie genres and worldwide gross collections.
- Provide interactive movie filtering and searching.
- Display movie information using Streamlit forms.

## 🛠️ Technologies Used
- Python
- Streamlit
- Pandas
- Matplotlib (if used)

## 📊 Dashboard Features

### 1. Dataset Exploration
- First 10 movie records
- Total rows and columns
- Column names and data types
- Missing value analysis

### 2. KPI Metrics
- Total Movies
- Average IMDb Rating
- Highest IMDb Rating
- Total Votes

### 3. Data Visualization
- Movies by Genre – Bar Chart
- IMDb Rating Distribution – Histogram
- Rating vs Votes – Scatter Plot
- Top 10 Movies by Worldwide Gross

### 4. Interactive Movie Explorer
- Genre Selection
- Country Selection
- IMDb Rating Slider
- Minimum Votes Filter
- Movie Title Search
- Rating Sorting
- Reset Filters

### 5. Movie Search Form
- Movie Title
- Preferred Genre
- Minimum IMDb Rating
- Session State Management
